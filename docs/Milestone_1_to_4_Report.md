## Final tech stack

- Backend: Python FastAPI
- Frontend: React.js
- Styling: Tailwind CSS
- Charts: Recharts
- Authentication: JWT
- Database: SQLite local, PostgreSQL through Docker Compose
- AI and analytics: Pandas, NumPy, Scikit-learn
- API testing: Swagger UI, Postman, Pytest
- DevOps: Docker and Docker Compose
- Version control: Git and GitHub
