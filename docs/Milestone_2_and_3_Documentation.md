# AI MetroFlow – Milestone 2 & 3 Documentation

## Overview
This document consolidates the architecture, API endpoints, Machine Learning pipelines, and frontend features developed during **Milestone 2 and Milestone 3**. These milestones focused on completing the Transportation Analytics & Prediction Engine, introducing Real-Time WebSockets, and finalizing the administrative dashboards.

---

## 1. Machine Learning & Prediction Engine

The AI MetroFlow Prediction Engine leverages multiple scikit-learn models serialized via `joblib`.

### Models Deployed (`ml/models/`)
1. **Passenger Demand Regressor (`demand_model.pkl`)**
   - **Algorithm:** Random Forest Regressor
   - **Purpose:** Predicts future passenger inflow at specific stations based on historical patterns, time of day, and calendar features.
2. **Delay Forecaster (`delay_classifier.pkl` & `delay_regressor.pkl`)**
   - **Algorithm:** Random Forest Classifier & Regressor
   - **Purpose:** Predicts the probability of a train delay occurring, and estimates the exact delay duration (in minutes).
3. **Anomaly Detection (`anomaly_model.pkl`)**
   - **Algorithm:** Isolation Forest
   - **Purpose:** Flags highly abnormal, unpredictable events (e.g., sudden protests, system-wide sensor failures, or extreme overcrowding). It analyzes deviations in footfall metrics that don't match typical historical distributions.

### Training Pipeline (`ml/train_models.py`)
- Automatically cleans raw datasets (`delhi_metro_updated.csv`, `public_transport_delays.csv`).
- Extracts temporal features (hour, day of week, weekend boolean).
- Trains all Random Forest and Isolation Forest models sequentially.
- Outputs `metrics.json` containing accuracy (MAE, RMSE, R² scores).

## 2. Backend REST API & WebSockets

### Core API Routers
- **Analytics API (`/api/analytics`)**: Fetches aggregated time-series data for rendering frontend charts. Includes metrics on peak travel times, average delays, and network-wide footfall.
- **Reports Export API (`/api/reports`)**: Compiles analytics logs and streams file downloads in `.csv`, `.xlsx`, or `.pdf` formats for external stakeholder reporting.
- **Heatmap API (`/api/heatmap`)**: Delivers spatial density arrays containing coordinates and intensity weights used to render the live Leaflet Heatmaps.
- **Announcements API (`/api/announcements`)**: Allows Admin users to broadcast urgent messages, operational alerts, or maintenance schedules to all connected operators.
- **Notifications API (`/api/notifications`)**: Stores and fetches localized user alerts (e.g., "Train 102 Delayed").

### Real-Time Telemetry (WebSockets)
- **Endpoint:** `WS /api/crowd/ws`
- **Functionality:** Provides a persistent bi-directional connection. The server broadcasts live station crowd counts, active train coordinate updates, and anomaly alerts (triggered by the ML engine) to all connected Vite clients. This eliminates the need for HTTP polling.

## 3. Frontend Dashboards & Visualizations

The React + Vite frontend was expanded to include rich administrative panels with premium glassmorphic UI aesthetics, dark mode support, and interactive visualizers.

### Key Pages
- **Analytics & Reports (`AnalyticsReports.jsx`)**: Utilizes `Recharts` to display time-series line charts, bar charts for station traffic, and pie charts for fleet status.
- **Spatial Heatmap (`HeatmapDashboard.jsx`)**: Integrates `react-leaflet` with heatmap plugins to visualize crowd density gradients across the metro network map.
- **Announcements Console (`AnnouncementsPage.jsx`)**: A management interface where administrators can draft, edit, and publish system-wide broadcast messages.
- **AI Prediction Console (`AIPrediction.jsx`)**: Interfaces directly with the Machine Learning endpoints to allow operators to run "what-if" scenarios and get live crowd forecasts and anomaly scores.

### Aesthetic System (`index.css`)
- **Animated Gradient Meshes**: Backgrounds feature moving, glowing orbs (`.gradient-mesh-bg`, `.blob`) for a highly modern feel.
- **Micro-Animations**: Shimmer effects on buttons (`.btn-shimmer`) and color transitions on data table rows (`.table-row-colorful`) provide responsive feedback.

---

## 4. Database Schema Updates (MongoDB)

New collections were introduced to support the Analytics and Communication features:
- `predictions`: Logs every prediction made by the ML models, including the confidence score, for future model retraining and auditing.
- `announcements`: Stores broadcast messages with timestamps, urgency levels (Info, Warning, Critical), and author references.
- `notifications`: Stores automated system alerts generated by anomaly triggers or schedule delays.

---

## 5. Deployment Notes

The entire Milestone 2 and 3 ecosystem is fully containerized.
- The `Dockerfile.backend` compiles the Python environment and automatically runs `train_models.py` during the build phase to ensure `.pkl` files are fresh.
- The `docker-compose.yml` orchestrates the MongoDB instance, the FastAPI backend, and the Vite frontend simultaneously.
