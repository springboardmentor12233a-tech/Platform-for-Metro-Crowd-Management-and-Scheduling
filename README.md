# 🚇 MetroFlow – AI-Based Metro Crowd Management and Scheduling Platform

## 📌 Project Overview

MetroFlow is an AI-powered web application that predicts metro crowd levels, monitors passenger traffic, provides intelligent recommendations, and assists metro authorities in managing train scheduling efficiently.

The platform uses Machine Learning, Flask, React, and Gemini AI to analyze passenger data and provide real-time insights through an interactive dashboard.

---

# 🎯 Objectives

- Predict metro crowd levels using Machine Learning.
- Forecast passenger traffic.
- Monitor metro station conditions in real time.
- Generate AI-based recommendations.
- Display live analytics through dashboards and charts.
- Improve passenger safety and operational efficiency.

# 🚀 Installation

## Backend

```bash
cd backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python src/app.py
```

---

## Frontend

```bash
cd frontend

npm install

npm start
```
