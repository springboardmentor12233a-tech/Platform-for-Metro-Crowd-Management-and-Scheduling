## Admin View

Admin can review all sections including all stations, schedules, alerts, analytics, and operational reports.

## Operator View

Operator can monitor station crowd status, passenger trends, schedule updates, congestion alerts, and recommendations.

## Milestone 4 UI Section

The dashboard includes a final Milestone 4 section with four main areas:

```text
Testing and workflow validation
Deployment readiness
Final demo flow
Milestone 4 outcomes
```

This section helps the mentor quickly verify that the application is tested, documented, Docker-ready, and prepared for final demonstration.
