# MetroFlow Frontend - Milestones 1 to 4

React frontend for the MetroFlow dashboard.

## Features

- Login page with admin and operator credentials
- Role-aware dashboard header
- Milestone 1: crowd monitoring, passenger trend, ticket split, station crowd table
- Milestone 2: traffic report, train schedule, frequency recommendations, AI demand forecasting
- Milestone 3: alerts, emergency announcements, live updates, congestion heatmap, analytics insights
- Milestone 4: testing validation summary, deployment readiness, final demo flow, milestone outcomes

## Run frontend

```powershell
cd frontend
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

## Build frontend

```powershell
npm run build
```
